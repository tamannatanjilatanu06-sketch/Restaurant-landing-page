  Restaurant Landing Page

📌 Project Overview

This is a modern and responsive Restaurant Landing Page developed using HTML and CSS. The main goal of this project is to create an attractive and user-friendly website for a restaurant.

The landing page features a clean layout, stylish design, and Font Awesome icons to enhance the overall user experience and visual appearance.

 Technologies Used

- HTML5 – For creating the structure of the website.
- CSS3 – For styling and designing the layout.
- Font Awesome – For adding attractive icons.

 Features

- Clean and modern user interface.
- Attractive restaurant landing page design.
- Font Awesome icons integration.
- Well-structured HTML and CSS code.
- User-friendly layout.

 Purpose

This project was created to practice and improve my frontend development skills using HTML and CSS.
